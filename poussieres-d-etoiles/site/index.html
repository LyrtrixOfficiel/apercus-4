Le nom

Pourquoi « Poussières d’étoiles » ?

Le nom vient d’une expression d’Hubert Reeves. L’astrophysicien rappelait que ce qui compose un corps s’est formé dans les étoiles.

Ici aussi, tout commence par une poussière.
